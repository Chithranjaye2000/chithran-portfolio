Preserve provenance and the original files when replacing or updating assets. The Appium documentation links its [OpenJS trademark policy](https://trademark-policy.openjsf.org/).

The assets are excluded from automatic formatting so the downloaded SVGs remain unmodified. Components use `object-fit: contain` with a neutral logo mat; they never invert, crop, or recolor the brand artwork.
